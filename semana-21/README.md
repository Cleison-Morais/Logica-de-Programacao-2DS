## Como baixar (não precisa de login)

1. Clique no arquivo **[index.html](index.html)**.
2. No canto direito, acima do código, clique no botão **Download raw file** (ícone de seta para baixo ⬇).
3. Abra o arquivo baixado no navegador (Chrome, Edge ou Firefox). Funciona sem internet.
