Como guardar dados sem usar arquivo

Construindo o conceitoGuardando dados na memória

Enquanto um programa está rodando, ele pode guardar informações na memória do computador (a memória RAM). Esses dados existem só enquanto o programa está aberto. Se o programa for encerrado sem salvar em um arquivo, tudo é perdido.

🧠 Memória (o que usamos nesta semana)

  • É rápida: o programa guarda e pega os dados na hora.
  • É temporária: fechou o programa, os dados somem.
  • Exemplo: a janela anônima e o nosso cadastro em lista.

💾 Arquivo (assunto para depois)

  • Fica gravado no disco ou na nuvem.
  • É permanente: os dados continuam lá depois de fechar.
  • Exemplo: um documento salvo, uma foto, um banco de dados.
Exemplo: um programa de agenda pode guardar os nomes dos contatos apenas enquanto está sendo usado. Ao fechar o programa sem salvar, todos esses contatos deixam de existir.

Construindo o conceitoUma lista guarda vários dados juntos

Uma lista guarda vários valores com um único nome. Em vez de criar uma variável para cada contato (contato1, contato2, contato3...), o programa guarda todos na mesma lista. A lista é criada com colchetes [] e novos elementos entram no final com append().

Com suas palavras: por que foi usada uma lista em vez de criar uma variável para cada contato?

Construindo o conceitoCada dado tem uma posição: o índice

Cada elemento da lista ocupa uma posição chamada índice. Atenção: a contagem começa no zero. O primeiro elemento está na posição 0, o segundo na posição 1, e assim por diante. Para pegar um elemento, usamos o nome da lista e o índice entre colchetes. Clique em cada caixinha:

# clique em uma caixinha para ver o código
Para lembrar: se a lista tem 3 elementos, os índices vão de 0 a 2. O último índice é sempre um a menos que o tamanho da lista. O tamanho é dado por len(contatos).

Construindo o conceitoSem arquivo, os dados não sobrevivem

As listas criadas durante a execução existem apenas na memória. Ao encerrar o programa, todos os dados da lista são perdidos. Para usar essas informações de novo, será preciso cadastrar tudo outra vez ou gravar em um arquivo, assunto que vamos estudar mais adiante.

Para refletir: se você cadastrasse dez produtos em um programa e o computador fosse desligado antes de salvá-los, o que aconteceria com esse cadastro?

Resumo para o cadernoO que aprendemos hoje

Enquanto um programa está em execução, ele pode guardar informações na memória do computador. Esses dados ficam disponíveis apenas enquanto o programa está aberto, como acontece na navegação privativa do navegador: quando a janela é fechada, tudo o que estava guardado desaparece. Para que os dados continuem existindo depois que o programa termina, eles precisam ser gravados em um arquivo.

Para guardar vários dados juntos, usamos uma lista. A lista tem um único nome e armazena muitos valores, em vez de precisarmos criar uma variável para cada um. Em Python, criamos uma lista vazia com produtos = [] e adicionamos elementos no final com produtos.append("Caderno").

Cada elemento ocupa uma posição chamada índice, e a contagem começa no zero: o primeiro elemento está na posição 0, o segundo na posição 1, e assim por diante. Para acessar um elemento, escrevemos o nome da lista com o índice entre colchetes, como em produtos[0]. A função len() informa quantos elementos a lista tem.

Resumo para o cadernoO que aprendemos hoje

Um cadastro em memória mantém os dados disponíveis apenas enquanto o programa está em execução. Depois que os dados estão guardados em uma lista, o programa pode fazer três operações principais com eles: cadastrar, consultar e listar.

Cadastrar é adicionar um novo dado, o que fazemos com append(), que coloca o elemento no final da lista. Consultar é procurar um dado específico: o operador in verifica se um valor está dentro da lista e, junto com o if e o else, permite avisar o usuário se o produto foi encontrado ou não. Listar é mostrar todos os dados guardados, um de cada vez, o que fazemos com o for, que percorre a lista do primeiro ao último elemento.

Usamos a consulta quando queremos saber sobre um item específico, como conferir se a papelaria tem caderno. Usamos a listagem quando queremos ver tudo o que está cadastrado, como conferir o estoque inteiro. É importante lembrar que o Python diferencia letras maiúsculas de minúsculas: "caderno" e "Caderno" são textos diferentes.

Ampliando o cadastro com listagem

    
Objetivo: ampliar o mesmo cadastro com a listagem dos produtos guardados na memória, sem usar arquivos, e fechar a primeira versão do sistema.

Construindo o conceitoA listagem caprichada

    
A papelaria precisa ver todos os produtos de uma vez, de um jeito organizado. A listagem tem três cuidados: numerar cada produto, avisar quando a lista está vazia e mostrar o total no final. Clique em cada parte da função:

    


def listar_produtos(produtos):
    if len(produtos) == 0:
        print("Nenhum produto cadastrado.")
    else:
        print("=== Produtos cadastrados ===")
        numero = 1
        for produto in produtos:
            preco = f"{produto[1]:.2f}".replace(".", ",")
            print(f"{numero}. {produto[0] + ' ':.<18} R$ {preco}")
            numero += 1
        print(f"Total de produtos: {len(produtos)}")

  • Lista vazia? Se o tamanho é zero, avisa e não tenta mostrar nada.

  • Senão, mostra o título da listagem.
    • 
        
  • Contador que começa em 1 e aumenta a cada produto, para numerar a lista (1, 2, 3...).
    • 
        
  • O for passa por todos os produtos, do primeiro ao último.
    • 
        
  • Formata a linha: o preço com 2 casas e vírgula, e o nome completado com pontinhos até 18 letras (:.<18).
    •
